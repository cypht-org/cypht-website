# Interface Overview

This guide provides a comprehensive overview of the Cypht interface, helping you navigate and use all the features effectively.

## Main Interface Layout

The Cypht interface is designed for efficiency and ease of use, with a clean, modern layout that adapts to different screen sizes.

### Layout Components

#### 1. Top Navigation Bar

- **Logo**: Cypht branding and home link
- **Search Bar**: Global search across all accounts
- **Account Switcher**: Quick access to different email accounts
- **Settings Menu**: Access to configuration options
- **User Profile**: Profile picture and account menu
- **Notifications**: Alert indicators and notification center

#### 2. Sidebar Navigation

- **Account List**: All connected email accounts
- **Folder Tree**: Email folders and labels
- **Quick Actions**: Common tasks and shortcuts
- **Navigation Menu**: Main application sections

#### 3. Main Content Area

- **Email List**: List of emails in selected folder
- **Preview Pane**: Email content preview
- **Compose Window**: Email composition interface
- **Settings Panels**: Configuration interfaces

## Navigation Elements

### Account Management

#### Account List

- **Account Icons**: Visual indicators for each account
- **Unread Counts**: Number of unread emails per account
- **Status Indicators**: Connection status and sync state
- **Quick Actions**: Mark as read, archive, delete

#### Account Switcher

- **Dropdown Menu**: List of all accounts
- **Search**: Find specific accounts quickly
- **Add Account**: Quick access to add new accounts
- **Account Settings**: Individual account configuration

### Folder Navigation

#### Folder Tree Structure

```
📧 Inbox (Combined)
├── 📧 Gmail
│   ├── 📥 Inbox
│   ├── 📤 Sent
│   ├── 📋 Drafts
│   └── 🗑️ Trash
├── 📧 Outlook
│   ├── 📥 Inbox
│   ├── 📤 Sent
│   └── 📋 Drafts
└── 📧 Yahoo
    ├── 📥 Inbox
    └── 📤 Sent
```

#### Folder Features

- **Expand/Collapse**: Click to show/hide subfolders
- **Unread Counts**: Number of unread emails in each folder
- **Drag & Drop**: Move emails between folders
- **Context Menu**: Right-click for folder options

### Email List Interface

#### List View Options

- **Compact View**: More emails visible at once
- **Comfortable View**: Larger spacing for easier reading
- **Preview View**: Show email preview in list
- **Card View**: Card-based layout for mobile

#### Email Information Display

- **Sender**: Email sender name and address
- **Subject**: Email subject line
- **Preview**: First few lines of email content
- **Date/Time**: When the email was received
- **Attachments**: Paperclip icon for emails with attachments
- **Flags**: Important, starred, or flagged emails

#### Selection and Actions

- **Checkbox Selection**: Select individual emails
- **Select All**: Select all emails in current view
- **Bulk Actions**: Delete, archive, move, label multiple emails
- **Keyboard Shortcuts**: Quick actions using keyboard

## Email Preview and Reading

### Preview Pane

- **Split View**: Email list and preview side by side
- **Full View**: Preview takes full width
- **Toggle View**: Switch between split and full view
- **Responsive**: Adapts to screen size

### Email Content Display

- **HTML Rendering**: Rich text emails display properly
- **Image Handling**: Images load with security controls

- **Attachment Preview**: View attachments inline

### Reading Tools

- **Zoom Controls**: Increase/decrease text size

## Composition Interface

## Keyboard Shortcuts

### Navigation Shortcuts

- **Ctrl/Cmd + 1-9**: Switch between accounts
- **Ctrl/Cmd + K**: Focus search bar
- **Ctrl/Cmd + N**: Compose new email
- **Ctrl/Cmd + R**: Refresh email list

### Email Actions

- **Delete**: Delete selected emails
- **Archive**: Archive selected emails
- **Mark as Read**: Mark emails as read
- **Reply**: Reply to selected email
- **Forward**: Forward selected email

### Interface Shortcuts

- **Ctrl/Cmd + ,**: Open settings
- **Ctrl/Cmd + Shift + T**: Toggle theme
- **Ctrl/Cmd + Shift + L**: Toggle sidebar
- **Esc**: Close current dialog
