# Search & Filters

Cypht's powerful search and filtering system helps you quickly find and organize your emails across all accounts.

## Global Search

### Search Interface

- **Search Bar**: Prominent search input at the top
- **Search Suggestions**: Auto-complete as you type
- **Search History**: Recent search queries
- **Advanced Search**: Detailed search options

### Search Types

- **Quick Search**: Simple keyword search
- **Advanced Search**: Multiple criteria search
- **Saved Search**: Predefined search queries
- **Smart Search**: AI-powered search suggestions

## Search Criteria

### Basic Search Fields

- **Keywords**: Search in subject, body, and sender
- **From**: Search by sender email address
- **To**: Search by recipient email address
- **Subject**: Search in email subject lines
- **Body**: Search in email content

### Advanced Search Fields

- **Date Range**: Search within specific date ranges
- **Account**: Search within specific accounts
- **Folder**: Search within specific folders
- **Size**: Search by email size
- **Attachments**: Search emails with/without attachments

### Special Search Operators

- **Quotes**: Exact phrase search ("exact phrase")
- **Wildcards**: Partial word matching (search\*)
- **Boolean**: AND, OR, NOT operators
- **Parentheses**: Group search terms

## Filter Options

### Quick Filters

- **Unread**: Show only unread emails
- **Read**: Show only read emails
- **Starred**: Show starred/flagged emails
- **Important**: Show important emails
- **Attachments**: Show emails with attachments
- **Today**: Show today's emails
- **This Week**: Show this week's emails

### Date Filters

- **Today**: Emails from today
- **Yesterday**: Emails from yesterday
- **This Week**: Emails from this week
- **Last Week**: Emails from last week
- **This Month**: Emails from this month
- **Custom Range**: Specify custom date range

### Sender Filters

- **Specific Sender**: Emails from specific person
- **Domain**: Emails from specific domain
- **Contact Groups**: Emails from contact groups
- **Blocked Senders**: Exclude blocked senders

### Account Filters

- **All Accounts**: Search across all accounts
- **Specific Account**: Search within one account
- **Account Groups**: Search within account groups
- **Primary Account**: Search primary account only

## Saved Searches

### Creating Saved Searches

1. Perform your search
2. Click "Save Search" button
3. Enter search name and description
4. Choose search scope and options
5. Save the search

### Managing Saved Searches

- **Edit**: Modify saved search criteria
- **Delete**: Remove saved searches
- **Share**: Share searches with others
- **Export**: Export search definitions

### Saved Search Features

- **Quick Access**: One-click access to saved searches
- **Search Shortcuts**: Keyboard shortcuts for saved searches
- **Search Notifications**: Get notified of new results
- **Search Analytics**: Track search usage

- Check system resources

#### Missing Results

- Check search criteria

- Check email indexing
