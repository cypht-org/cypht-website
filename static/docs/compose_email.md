# Compose Email

Create and send emails with advanced formatting options.

## Overview

The Compose feature provides a powerful email composition interface with rich text editing and advanced options.

![Compose Email](/img/Compose.PNG)

## Basic Composition

### Email Fields

- **To**: Primary recipients
- **CC**: Carbon copy recipients
- **BCC**: Blind carbon copy recipients
- **Subject**: Email subject line
- **Body**: Email content

### Rich Text Editor

- Bold, italic, underline formatting
- Font size and color options
- Bullet points and numbered lists
- Text alignment options
- Link insertion

## Advanced Features

### Attachments

- File upload support
- Drag and drop functionality
- Multiple file selection
- File size limits
- Attachment preview

### Templates

- Pre-defined email templates
- Custom template creation
- Template variables
- Quick template insertion
- Template management

### Signatures

- Multiple signature support
- Account-specific signatures
- Rich text signatures
- Automatic signature insertion
- Signature management
