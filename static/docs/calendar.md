# Calendar

Cypht's integrated calendar provides powerful scheduling and event management capabilities alongside your email.

## Calendar Overview

### Calendar Features

- **Event Management**: Create, edit, and delete events
- **Multiple Calendars**: Manage multiple calendar sources
- **Event Integration**: Create events from emails
- **Reminder System**: Email and popup reminders

### Calendar Views

- **Month View**: Monthly calendar overview
- **Week View**: Weekly schedule view
- **Day View**: Daily detailed view
- **Agenda View**: List of upcoming events

## Calendar Interface

### Main Calendar Window

- **Navigation**: Month, week, day navigation
- **View Switcher**: Switch between different views
- **Date Picker**: Quick date selection
- **Today Button**: Jump to current date

### Calendar Display

- **Event Blocks**: Visual event representation
- **Color Coding**: Different colors for different calendars
- **Event Details**: Hover for event information
- **All-Day Events**: Special display for all-day events

### Calendar Controls

- **Zoom**: Zoom in/out on calendar
- **Scroll**: Navigate through time
- **Filter**: Show/hide specific calendars
- **Search**: Search for events

## Event Management

### Creating Events

1. Click on calendar date/time
2. Enter event details
3. Set event properties
4. Choose calendar
5. Save event

### Event Properties

- **Title**: Event name
- **Description**: Event description
- **Date/Time**: Start and end times
- **Location**: Event location
- **Attendees**: Event participants

### Event Types

- **Regular Events**: Standard calendar events
- **All-Day Events**: Events lasting all day
- **Recurring Events**: Repeating events
- **Meeting Events**: Events with attendees

- Review sync logs

#### Reminders Not Working

- Review reminder logs
