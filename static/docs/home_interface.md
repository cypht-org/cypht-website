# Home Interface

Understand the main dashboard and navigation elements of Cypht.

## Main Dashboard

The Cypht home interface provides a unified view of all your email accounts and features.

![Cypht Home Interface](/img/home.PNG)

## Navigation Elements

### Top Navigation Bar

- **Logo**: Cypht branding and home link
- **Account Switcher**: Switch between different email accounts
- **Settings**: Access configuration options
- **User Profile**: Manage your profile and preferences

### Sidebar Navigation

- **Inbox**: Combined view of all emails
- **Compose**: Create new emails
- **Contacts**: Manage your contact book
- **Calendar**: Schedule and view events
- **Settings**: Account and application settings

### Main Content Area

- **Email List**: View and manage your emails
- **Preview Pane**: Quick email preview
- **Action Buttons**: Common email actions (reply, forward, delete, etc.)

## Key Features

### Unified Inbox

View emails from all your connected accounts in one place.

### Quick Actions

- Mark as read/unread
- Archive emails
- Move to folders
- Delete messages

### Search Functionality

- Global search across all accounts
- Advanced search filters
- Saved search queries

## Customization Options

### Layout Preferences

- Choose between different layout styles
- Adjust sidebar width
- Customize email list density

### Theme Options

- Light and dark themes
- Custom color schemes
- Font size adjustments
