   <h1 id="adding-email-accounts">Adding Email Accounts</h1>
<p>Connect your email accounts to Cypht for unified management.</p>
<h2 id="supported-email-providers">Supported Email Providers</h2>
<p>Cypht supports a wide range of email providers:</p>
<h3 id="popular-providers">Popular Providers</h3>
<ul>
<li><strong>Gmail</strong> (IMAP/SMTP)</li>
<li><strong>Outlook/Hotmail</strong> (IMAP/SMTP)</li>
<li><strong>Yahoo Mail</strong> (IMAP/SMTP)</li>
<li><strong>Apple iCloud</strong> (IMAP/SMTP)</li>
<li><strong>Exchange Server</strong> (EWS)</li>
<li><strong>Office 365</strong> (EWS/IMAP)</li>
</ul>
<h3 id="custom-imap-smtp">Custom IMAP/SMTP</h3>
<ul>
<li>Any IMAP/SMTP compatible server</li>
<li>Custom port configurations</li>
<li>SSL/TLS encryption support</li>
</ul>
<h2 id="adding-your-first-account">Adding Your First Account</h2>
<p><img src="/img/Add.PNG" alt="Add Email Account"></p>
<h3 id="step-by-step-process">Step-by-Step Process</h3>
<ol>
<li><p><strong>Access Account Settings</strong></p>
<ul>
<li>Click on the settings icon</li>
<li>Select &quot;Add Account&quot;</li>
<li>Choose your email provider</li>
</ul>
</li>
<li><p><strong>Enter Account Details</strong></p>
<ul>
<li>Email address</li>
<li>Password or app-specific password</li>
<li>Server settings (if custom)</li>
</ul>
</li>
<li><p><strong>Configure Server Settings</strong></p>
<ul>
<li>IMAP server address</li>
<li>SMTP server address</li>
<li>Port numbers</li>
<li>Security settings (SSL/TLS)</li>
</ul>
</li>
<li><p><strong>Test Connection</strong></p>
<ul>
<li>Verify IMAP connection</li>
<li>Test SMTP sending</li>
<li>Confirm folder synchronization</li>
</ul>
</li>
</ol>
<h2 id="oauth-integration">OAuth Integration</h2>
<h3 id="gmail-oauth-setup">Gmail OAuth Setup</h3>
<ol>
<li>Enable OAuth in Gmail settings</li>
<li>Configure OAuth credentials in Cypht</li>
<li>Complete OAuth flow</li>
<li>Grant necessary permissions</li>
</ol>
<h3 id="outlook-office-365-oauth">Outlook/Office 365 OAuth</h3>
<ol>
<li>Register application in Azure AD</li>
<li>Configure OAuth settings</li>
<li>Complete authentication flow</li>
<li>Set up calendar and contacts sync</li>
</ol>
<h2 id="advanced-configuration">Advanced Configuration</h2>
<h3 id="multiple-accounts">Multiple Accounts</h3>
<ul>
<li>Add unlimited email accounts</li>
<li>Organize accounts by category</li>
<li>Set default sending account</li>
<li>Configure account-specific settings</li>
</ul>
<h3 id="security-settings">Security Settings</h3>
<ul>
<li>Two-factor authentication</li>
<li>App-specific passwords</li>
<li>OAuth 2.0 authentication</li>
<li>Encrypted connections</li>
</ul>
<h3 id="folder-management">Folder Management</h3>
<ul>
<li>Sync specific folders only</li>
<li>Exclude large folders</li>
<li>Set folder display preferences</li>
<li>Configure folder permissions</li>
</ul>
<h2 id="troubleshooting">Troubleshooting</h2>
<h3 id="common-issues">Common Issues</h3>
<ul>
<li><strong>Authentication Failed</strong>: Check credentials and 2FA settings</li>
<li><strong>Connection Timeout</strong>: Verify server settings and firewall</li>
<li><strong>SSL Errors</strong>: Update certificates or disable SSL verification</li>
<li><strong>Sync Issues</strong>: Check folder permissions and server limits</li>
</ul>
<h3 id="getting-help">Getting Help</h3>
<ul>
<li>Review server logs</li>
<li>Check provider-specific documentation</li>
<li>Contact your email provider support</li>
<li>Consult Cypht community forums</li>
</ul>
