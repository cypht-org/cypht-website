# Compose & Send Emails

Cypht's email composition interface provides powerful tools for creating, formatting, and sending professional emails.

## Composition Interface

### Main Compose Window

- **Full-Screen Mode**: Dedicated composition window
- **Inline Mode**: Compose within main interface
- **Modal Mode**: Popup composition window
- **Responsive Design**: Adapts to all screen sizes

### Composition Layout

- **Header Section**: Recipients, subject, and options
- **Toolbar**: Formatting and action buttons
- **Content Area**: Rich text editor
- **Footer Section**: Signatures and send options

## Recipient Management

### Address Fields

- **To Field**: Primary recipients
- **CC Field**: Carbon copy recipients
- **BCC Field**: Blind carbon copy recipients
- **Reply-To**: Custom reply-to address

### Address Features

- **Auto-Complete**: Smart contact suggestions
- **Contact Search**: Search through contact book
- **Recent Recipients**: Quick access to recent contacts
- **Group Support**: Send to contact groups
- **Validation**: Email address format validation

### Recipient Options

- **Multiple Recipients**: Add multiple email addresses
- **Recipient Groups**: Send to predefined groups
- **Distribution Lists**: Use distribution lists
- **Recipient Validation**: Verify email addresses

## Email Content

### Rich Text Editor

- **Formatting Toolbar**: Bold, italic, underline, strikethrough
- **Font Options**: Font family, size, and color
- **Text Alignment**: Left, center, right, justify
- **Lists**: Bulleted and numbered lists
- **Links**: Insert and edit hyperlinks
- **Images**: Insert and resize images

### Advanced Formatting

- **Tables**: Create and edit tables
- **Code Blocks**: Insert code snippets
- **Quotes**: Block quotes and citations
- **Headers**: Different heading levels
- **Horizontal Rules**: Visual separators

### Content Tools

- **Spell Check**: Real-time spelling correction
- **Word Count**: Character and word count
- **Undo/Redo**: Action history management
- **Find/Replace**: Search and replace text
- **Paste Options**: Paste with or without formatting

## Attachments

### File Upload

- **Drag & Drop**: Drag files directly into compose window
- **File Browser**: Browse and select files
- **Multiple Files**: Upload multiple files at once

- **Audio/Video**: MP3, MP4, AVI, MOV

### Attachment Management

- **Preview**: Preview attachments before sending
- **Remove**: Remove unwanted attachments
- **Rename**: Rename attachment files
- **Size Limits**: Automatic size validation

## Troubleshooting

### Common Issues

#### Composition Window Not Opening

- Check browser JavaScript
- Clear browser cache
- Verify popup blockers
- Check browser permissions

#### Attachments Not Uploading

- Check file size limits
- Verify file permissions
- Test network connection
- Check server configuration

#### Formatting Issues

- Check browser compatibility
- Verify rich text editor
- Test with different browsers
- Clear browser cache

### Getting Help

- Check composition settings
- Review error messages
- Contact support team
- Visit community forum

## Best Practices

### Email Composition

- Use clear, concise subject lines
- Keep emails focused and relevant
- Use proper formatting and structure
- Proofread before sending

### Security Best Practices

- Use encryption for sensitive emails
- Be cautious with attachments
- Verify recipient addresses
- Use digital signatures when appropriate

### Performance Tips

- Compose offline when possible
- Use templates for common emails
- Optimize attachment sizes
- Schedule emails for optimal delivery

The compose interface in Cypht provides all the tools you need to create professional, secure, and effective emails.
