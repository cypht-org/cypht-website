# Labels & Folders

Cypht's labeling and folder system provides powerful tools for organizing and categorizing your emails across all accounts.

## Folder System

### Folder Types

- **System Folders**: Inbox, Sent, Drafts, Trash, Spam
- **Custom Folders**: User-created folders
- **Smart Folders**: Dynamic folders based on rules
- **Shared Folders**: Folders shared with other users

### Folder Structure

- **Hierarchical**: Nested folder organization
- **Flat Structure**: Simple folder list
- **Mixed Structure**: Combination of both approaches
- **Account-Specific**: Folders per email account

### Folder Management

- **Create Folders**: Add new folders
- **Rename Folders**: Change folder names
- **Move Folders**: Reorganize folder structure
- **Delete Folders**: Remove unwanted folders

## Label System

### Label Types

- **Text Labels**: Simple text-based labels
- **Color Labels**: Color-coded labels
- **Icon Labels**: Labels with icons
- **Smart Labels**: Automatically applied labels

### Label Features

- **Multiple Labels**: Apply multiple labels to emails
- **Label Hierarchy**: Organize labels in categories
- **Label Colors**: Customize label colors
- **Label Icons**: Add icons to labels

### Label Management

- **Create Labels**: Add new labels
- **Edit Labels**: Modify label properties
- **Delete Labels**: Remove labels
- **Merge Labels**: Combine similar labels

## Folder Operations

### Creating Folders

1. Right-click in folder tree
2. Select "New Folder"
3. Enter folder name
4. Choose parent folder
5. Set folder permissions

### Folder Properties

- **Name**: Folder display name
- **Description**: Folder description
- **Permissions**: Access permissions
- **Sync Settings**: Synchronization options

### Folder Actions

- **Rename**: Change folder name
- **Move**: Move to different location
- **Copy**: Duplicate folder
- **Delete**: Remove folder and contents

## Label Operations

### Creating Labels

1. Go to Settings → Labels
2. Click "Create Label"
3. Enter label name
4. Choose label color
5. Set label properties

### Label Properties

- **Name**: Label display name
- **Color**: Label color
- **Icon**: Label icon
- **Description**: Label description

### Label Actions

- **Apply**: Add label to emails
- **Remove**: Remove label from emails
- **Edit**: Modify label properties
- **Delete**: Remove label
