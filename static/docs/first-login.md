# First Login

Welcome to Cypht! This guide will help you get started with your first login and initial account setup.

## Accessing Cypht

### Web Browser Access

1. Open your web browser
2. Navigate to your Cypht installation URL:
   - Production: `https://your-domain.com`
   - Development: `http://localhost/cypht`

### System Requirements Check

Before logging in, ensure your browser meets the requirements:

- JavaScript enabled
- Cookies enabled
- Modern browser (Chrome 80+, Firefox 75+, Safari 13+, Edge 80+)

## Login Process

### 1. Login Page

When you first access Cypht, you'll see the login page with:

- Username/email field
- Password field
- "Remember me" option
- "Forgot password" link
- Language selector

### 2. Default Admin Account

If this is a fresh installation, use the default admin credentials:

- **Username**: `admin`
- **Password**: `admin` (change immediately after first login)

### 3. First Login Security

On your first login, you'll be prompted to:

- Change the default password
- Set up security questions
- Configure two-factor authentication (optional)
- Set your timezone and language preferences

## Initial Setup Wizard

After successful login, you'll be guided through the setup wizard:

### Step 1: Profile Setup

- **Full Name**: Your display name
- **Email Address**: Primary email address
- **Avatar**: Upload profile picture (optional)
- **Timezone**: Select your timezone
- **Language**: Choose interface language

### Step 2: Security Configuration

- **Password**: Set a strong password
- **Security Questions**: Set up recovery questions
- **Two-Factor Authentication**: Enable 2FA (recommended)
- **Session Timeout**: Configure session duration

### Step 3: Email Account Setup

- **Add First Account**: Connect your primary email
- **Account Type**: Choose provider or custom setup
- **Server Settings**: Configure IMAP/SMTP settings
- **Test Connection**: Verify account connectivity

### Step 4: Interface Preferences

- **Theme**: Choose light, dark, or auto theme
- **Layout**: Select interface layout
- **Notifications**: Configure notification preferences
- **Keyboard Shortcuts**: Enable/disable shortcuts

## Adding Your First Email Account

### Quick Setup (Popular Providers)

#### Gmail Setup

1. Click "Add Account" → "Gmail"
2. Enter your Gmail address
3. Click "Continue with Google"
4. Grant necessary permissions
5. Account will be automatically configured

#### Outlook/Office 365 Setup

1. Click "Add Account" → "Outlook"
2. Enter your email address
3. Click "Continue with Microsoft"
4. Complete OAuth authentication
5. Account will be automatically configured

#### Yahoo Mail Setup

1. Click "Add Account" → "Yahoo"
2. Enter your Yahoo email address
3. Use app-specific password (not regular password)
4. Grant permissions if prompted
5. Account will be configured

### Manual Setup (Custom Servers)

#### IMAP Settings

- **Server**: Your IMAP server address
- **Port**: Usually 993 (SSL) or 143 (TLS)
- **Encryption**: SSL/TLS
- **Username**: Your email address
- **Password**: Your email password

#### SMTP Settings

- **Server**: Your SMTP server address
- **Port**: Usually 587 (TLS) or 465 (SSL)
- **Encryption**: TLS/SSL
- **Authentication**: Required
- **Username**: Your email address
- **Password**: Your email password

### Advanced Settings

- **Folder Sync**: Choose which folders to sync
- **Sync Frequency**: Set how often to check for new emails
- **Storage Limit**: Set local storage limits
- **Offline Access**: Enable offline email access

## Troubleshooting First Login

### Common Issues

#### Cannot Access Login Page

- Check web server configuration
- Verify SSL certificate
- Check firewall settings
- Ensure PHP is running

#### Login Credentials Not Working

- Verify username and password
- Check for caps lock
- Clear browser cache and cookies
- Try different browser

#### Email Account Connection Fails

- Verify email server settings
- Check internet connectivity
- Ensure email provider allows IMAP/SMTP
- Try app-specific password for Gmail/Yahoo

#### Interface Not Loading Properly

- Check JavaScript is enabled
- Clear browser cache
- Try different browser
- Check browser console for errors
