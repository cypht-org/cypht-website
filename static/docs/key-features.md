# Key Features

Cypht offers a comprehensive set of features designed to enhance your email experience while maintaining security and privacy.

<div class="core-features">
## Core Email Features
</div>

### Unified Inbox

- **Multi-Account Support**: View emails from all your accounts in one place
- **Smart Organization**: Automatic categorization and priority sorting
- **Real-Time Sync**: Instant updates across all connected accounts
- **Thread Grouping**: Related emails grouped together for easy reading

### Advanced Composition

- **Rich Text Editor**: Full formatting capabilities with HTML support
- **Template System**: Pre-defined templates for common emails
- **Attachment Support**: Drag-and-drop file uploads with preview
- **Draft Management**: Auto-save and draft synchronization

### Powerful Search

- **Global Search**: Search across all accounts simultaneously
- **Advanced Filters**: Date, sender, subject, and content filtering
- **Saved Searches**: Create and save complex search queries
- **Search Suggestions**: Intelligent autocomplete and suggestions

<div class="feature-category">
## Organization & Management

### Smart Filtering

</div>

- **Sieve Filters**: Server-side email filtering and organization
- **Automatic Sorting**: Emails automatically sorted into folders
- **Spam Protection**: Advanced spam detection and blocking
- **Custom Rules**: Create complex filtering rules

### Label & Folder System

- **Hierarchical Folders**: Organize emails in nested folder structures
- **Color-Coded Labels**: Visual organization with custom colors
- **Quick Actions**: One-click email organization
- **Bulk Operations**: Manage multiple emails simultaneously

### Contact Management

- **Unified Address Book**: All contacts in one place
- **Auto-Complete**: Smart suggestions while composing
- **Contact Groups**: Organize contacts into groups
- **Import/Export**: Support for vCard and CSV formats

<div class="security-section">
## Security & Privacy

### Encryption Support

</div>

- **PGP Integration**: Full PGP encryption and signing
- **S/MIME Support**: Enterprise-grade email encryption
- **TLS/SSL**: Secure connections to email servers
- **Certificate Management**: Easy certificate import and management

### Privacy Features

- **No Data Collection**: Your emails never leave your servers
- **Self-Hosted**: Complete control over your data
- **Session Security**: Secure session management
- **CSRF Protection**: Built-in security against attacks

### Authentication

- **Two-Factor Authentication**: Enhanced account security
- **OAuth Integration**: Secure login with Google, Microsoft, etc.
- **Password Management**: Secure password storage and generation
- **Session Management**: Configurable session timeouts

- **Recurring Emails**: Set up automatic recurring messages

### Advanced Actions

- **Snooze Feature**: Temporarily hide emails and bring them back later

- **Block List**: Block unwanted senders and domains
- **Auto-Reply**: Set up automatic responses
