# Unified Inbox

The Unified Inbox is Cypht's core feature that brings all your email accounts together in one powerful, organized interface.

## Overview

The Unified Inbox provides a single view of all your emails across multiple accounts, making it easy to manage your entire email communication from one place.

### Key Benefits

- **Centralized Management**: All emails in one interface
- **Cross-Account Organization**: Organize emails regardless of source account
- **Unified Search**: Search across all accounts simultaneously
- **Consistent Experience**: Same interface for all email accounts

## Inbox Interface

### Main Inbox View

- **Combined View**: All emails from all accounts
- **Account-Specific View**: Filter by individual accounts
- **Folder View**: Organize by folders across accounts
- **Smart View**: AI-powered email categorization

### Email List Display

- **Sender Information**: Name and email address
- **Subject Line**: Email subject with preview
- **Timestamp**: When the email was received
- **Account Indicator**: Visual indicator of source account
- **Status Icons**: Read/unread, attachments, flags

### Visual Indicators

- **Unread Count**: Number of unread emails per account
- **Account Colors**: Color-coded account identification
- **Priority Flags**: Important email indicators
- **Attachment Icons**: Paperclip for emails with attachments
