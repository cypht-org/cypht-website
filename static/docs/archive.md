# Archive

The Archive feature provides long-term storage and organization for your emails, helping you maintain a clean inbox while preserving important messages.

## What is Archive?

Archive is a storage system that:

- Removes emails from your inbox without deleting them
- Provides long-term storage for important emails
- Helps maintain a clean and organized inbox
- Preserves emails for future reference

## Archive Features

### Basic Archiving

- **One-Click Archive**: Quick archive action
- **Bulk Archive**: Archive multiple emails
- **Auto-Archive**: Automatic archiving based on rules
- **Archive Search**: Search archived emails

### Archive Organization

- **Archive Folders**: Organize archived emails
- **Archive Categories**: Categorize archived content
- **Archive Tags**: Tag archived emails
- **Archive Dates**: Organize by archive date
