# Basic Settings

This guide covers the essential settings you need to configure for optimal Cypht performance and user experience.

## Accessing Settings

### Settings Menu Location

- **Desktop**: Click your profile picture → Settings
- **Mobile**: Tap the menu button → Settings
- **Direct URL**: Navigate to `/settings` in your browser

### Settings Categories

- **Account Settings**: Email account configuration
- **Interface Settings**: Appearance and layout
- **Security Settings**: Password and authentication
- **Notification Settings**: Alerts and notifications
- **Advanced Settings**: Power user options

## Account Settings

### Email Account Management

#### Adding New Accounts

1. Go to Settings → Accounts
2. Click "Add Account"
3. Choose account type:
   - **Gmail**: OAuth setup
   - **Outlook**: OAuth setup
   - **Yahoo**: App password setup
   - **Custom**: Manual IMAP/SMTP setup

#### Account Configuration

- **Display Name**: How the account appears in the interface
- **Default Account**: Set as primary sending account
- **Sync Frequency**: How often to check for new emails
- **Folder Sync**: Which folders to synchronize
- **Storage Limit**: Maximum local storage per account

#### Account Security

- **App Passwords**: Use app-specific passwords for Gmail/Yahoo
- **OAuth Tokens**: Manage OAuth authentication tokens
- **Connection Security**: SSL/TLS encryption settings
- **Certificate Validation**: SSL certificate verification

### Signature Management

#### Creating Signatures

1. Go to Settings → Signatures
2. Click "Add Signature"
3. Configure signature:
   - **Name**: Signature identifier
   - **Content**: Rich text signature content
   - **Default**: Set as default signature
   - **Account Specific**: Assign to specific accounts

#### Signature Options

- **Rich Text**: HTML formatting support
- **Plain Text**: Simple text signatures
- **Auto-Insert**: Automatically add to new emails
- **Conditional**: Insert based on recipient or account

## Interface Settings

### Theme and Appearance

#### Theme Selection

- **Light Theme**: Clean, bright interface
- **Dark Theme**: Easy on the eyes, battery friendly
- **Auto Theme**: Follows system preference
- **Custom Theme**: User-defined color schemes

#### Layout Options

- **Sidebar Position**: Left or right sidebar placement
- **Preview Position**: Right or bottom email preview
- **List Density**: Compact or comfortable spacing
- **Font Size**: Adjustable text size (12px - 18px)

#### Visual Customization

- **Accent Color**: Primary interface color
- **Background**: Custom background images
- **Icons**: Different icon sets
- **Animations**: Enable/disable interface animations

### Display Preferences

#### Email List Display

- **View Mode**: List, card, or compact view
- **Sort Order**: Date, sender, subject, size
- **Grouping**: Group by date, sender, or folder
- **Preview Length**: Number of preview lines

#### Email Content Display

- **Font Family**: Choose email display font
- **Font Size**: Adjustable reading font size
- **Line Height**: Spacing between lines
- **Margins**: Email content margins

## Security Settings

### Password and Authentication

#### Password Management

- **Change Password**: Update your login password
- **Password Strength**: View password strength indicator
- **Password History**: Prevent password reuse
- **Password Expiry**: Set password expiration (optional)

#### Two-Factor Authentication

1. Go to Settings → Security → 2FA
2. Choose authentication method:
   - **TOTP**: Time-based one-time passwords
   - **SMS**: Text message codes
   - **Email**: Email-based codes
3. Follow setup instructions
4. Save backup codes

#### Session Management

- **Session Timeout**: Automatic logout time
- **Remember Me**: Extended session duration
- **Device Management**: View logged-in devices
- **Force Logout**: Log out all devices

### Privacy Settings

#### Data Protection

- **Data Retention**: How long to keep local data
- **Cache Management**: Clear cached data
- **Log Retention**: How long to keep logs
- **Analytics**: Opt-in/out of usage analytics

#### Encryption Options

- **Email Encryption**: PGP/S/MIME support
- **Connection Encryption**: SSL/TLS settings
- **Local Encryption**: Encrypt local data
- **Key Management**: Manage encryption keys

## Backup and Restore

### Data Backup

#### Automatic Backups

- **Backup Frequency**: Daily, weekly, or monthly
- **Backup Location**: Local or cloud storage
- **Backup Content**: Settings, emails, contacts
- **Backup Retention**: How long to keep backups

#### Manual Backup

1. Go to Settings → Backup & Restore
2. Click "Create Backup"
3. Choose backup content:
   - **Settings**: Configuration files
   - **Emails**: Email data and folders
   - **Contacts**: Contact book data
   - **Calendar**: Calendar events
4. Download backup file

### Data Restore

1. Go to Settings → Backup & Restore
2. Click "Restore from Backup"
3. Upload backup file
4. Choose what to restore
5. Confirm restoration

## Troubleshooting Settings

### Common Issues

#### Settings Not Saving

- Check browser permissions
- Clear browser cache
- Verify server write permissions
- Check for JavaScript errors

#### Performance Issues

- Reduce sync frequency
- Clear cache and temporary files
- Disable unnecessary features
- Check system resources

#### Connection Problems

- Verify email server settings
- Check firewall configuration
- Test network connectivity
- Review SSL certificate settings

### Reset Settings

If you encounter persistent issues:

1. Go to Settings → Advanced → Reset
2. Choose reset options:
   - **Interface Settings**: Reset appearance settings
   - **Account Settings**: Reset email account settings
   - **All Settings**: Complete settings reset
3. Confirm reset action

### Security Best Practices
