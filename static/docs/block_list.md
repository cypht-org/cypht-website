# Block List

Block unwanted senders and domains to improve your email experience.

## Overview

The Block List feature allows you to automatically block emails from specific senders or domains, helping you maintain a clean inbox.

![Block List](/img/block_list.png)

## Blocking Options

### Block by Email Address

- Block specific email addresses
- Permanent blocking
- Immediate effect
- Easy management

### Block by Domain

- Block entire domains
- Catch-all blocking
- Subdomain handling
- Wildcard support

### Block by Pattern

- Pattern-based blocking
- Regular expressions
- Flexible matching
- Advanced filtering

## Managing Block Lists

### Adding to Block List

1. Select unwanted email
2. Click "Block Sender"
3. Choose blocking type
4. Confirm action
5. Review block list

### Block List Management

- View all blocked items
- Edit blocking rules
- Remove from block list
- Bulk operations
- Import/export lists

### Block List Categories

- **Spam**: Known spam sources
- **Unwanted**: Unwanted newsletters
- **Personal**: Personal blocks
- **Temporary**: Time-limited blocks
