# Email Encryption (PGP / S/MIME)

Cypht supports both PGP and S/MIME encryption to provide end-to-end email security and privacy.

## What is Email Encryption?

Email encryption is a security feature that:

- Protects email content from unauthorized access
- Ensures only intended recipients can read emails
- Provides authentication and integrity verification
- Maintains privacy and confidentiality

## Encryption Types

### PGP Encryption

- **OpenPGP Standard**: Industry-standard encryption
- **Public/Private Keys**: Asymmetric encryption
- **Digital Signatures**: Verify sender identity
- **Cross-Platform**: Works across different systems

### S/MIME Encryption

- **X.509 Certificates**: Standard certificate format
- **Enterprise Support**: Widely supported in enterprises
- **Certificate Authority**: Trusted certificate authorities
- **Integration**: Easy integration with existing systems
