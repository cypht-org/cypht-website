# Combined Inbox

View all your emails from different accounts in one unified inbox.

## Overview

The Combined Inbox feature allows you to see emails from all your connected accounts in a single, organized view.

![Combined Inbox](/img/Inbox.PNG)

## Key Features

### Unified View

- All emails in one place
- Account indicators for each email
- Consistent interface across accounts
- Real-time synchronization

### Smart Organization

- Automatic categorization
- Priority-based sorting
- Thread grouping
- Unread count indicators

### Quick Actions

- Mark as read/unread
- Archive messages
- Move to folders
- Delete emails
- Flag important messages

## Navigation

### Account Filtering

- View all accounts combined
- Filter by specific account
- Quick account switcher
- Account-specific actions

### Folder Management

- Unified folder view
- Account-specific folders
- Custom folder organization
- Folder synchronization status

## Advanced Features

### Search and Filter

- Global search across all accounts
- Advanced filtering options
- Saved search queries
- Search within specific accounts

### Email Threading

- Conversation grouping
- Thread expansion/collapse
- Reply tracking
- Thread-based actions

### Bulk Operations

- Bulk actions (delete, move, archive)
- Batch operations
- Progress indicators
