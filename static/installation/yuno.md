      <div id="step" class="g-page-card">
            <div class="g-card-header">
             <h4>Steps</h5>
            </div>
            <div class="g-card-body ms-3">
                  <p>
                        YunoHost simplifies server administration to democratize self-hosting while remaining reliable, secure, ethical and lightweight.
                        It’s a Debian-based distribution installable on many types of hardware. Learn more at
                        <a href="https://yunohost.org/en/whatsyunohost">https://yunohost.org/en/whatsyunohost</a>.
                   </p>
                   <p>To install Cypht on YunoHost, follow these steps:</p>
                  <ul>
                        <li>If you don’t have a YunoHost server, see <a href="https://yunohost.org/#/install">the install guide</a>.</li>
                        <li>From the admin dashboard, go to “Applications”.</li>
                        <li>Click “Install”.</li>
                        <li>Search for “cypht”.</li>
                        <li>Select the Cypht app.</li>
                        <li>Fill the form as needed (or keep defaults) and click “Install”. Ensure the URL is not already used by another app.</li>
                        <li>Wait for installation to complete and return to the dashboard.</li>
                        <li>Open the app via the “open the app” button.</li>
                        <li>Login using the admin credentials provided during installation and start configuring email accounts.</li>
                  </ul>
            </div>
