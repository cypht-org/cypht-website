## User Interface Overview {#overview}

Cypht features a clean, modern interface designed for efficiency and ease of use. The web-based UI provides instant
access to all your email accounts and RSS feeds from a single, unified dashboard.

Built with responsive design principles, Cypht works seamlessly across desktop, tablet, and mobile devices, ensuring
you can manage your communications anywhere, anytime.

## Main Layout Components {#main_layout}

The Cypht interface is organized into logical sections that work together to provide an intuitive email management
experience.

:::grid
- **Navigation Panel**

  Left sidebar containing folder hierarchy, account switching, and quick access to combined views (inbox, sent,

  ![Cypht settings screenshot](/img/docs/settings_tab.webp)
  Top navigation with account management, module configuration, theme selection, and user preferences. Always
  accessible for quick adjustments.
:::

## Combined Views {#combined_views}

Cypht, your email client that allows you to access multiple email accounts simultaneously, features main folders such
as Drafts, Everything, Flagged, Junk, Sent, Snoozed, Trash, and Unread.

To ensure that email messages from your accounts appear in these folders, you need to add them by accessing the
respective folder and clicking the "Add this folder to combined pages" icon located in the header of your folder view.
This action integrates the folder into the combined view, making it easier to manage emails across all your accounts
in one place. Refer to the provided image for visual guidance.

## Unified Inbox {#unified_inbox}

The advanced and most efficient service of Cypht enables users to access multiple email accounts at the same time.
Users can view inboxes of different email providers and can send, receive, and manage email messages from the
interactive webmail.

The webmail also provides functionality to search, sort, and filter emails across all connected accounts.

## Interface Customization {#customization}

Adapt the Cypht interface to match your workflow and preferences with extensive customization options.

- **Theme System :** Multiple built-in themes including light, dark, and high-contrast options with custom CSS support
- **Message Density :** Compact, comfortable, or spacious display modes for different screen sizes and preferences
- **Language Support :** Right-to-left language support and easy translation system for international users

:::warning
**Module-Driven Interface.** Remember that Cypht's interface is built entirely from modules. Additional interface
components and features can be added by enabling different module sets in the settings.
:::

## Accessibility & Responsive Design {#accessibility}

Cypht is committed to providing an accessible experience for all users, with comprehensive support for assistive
technologies and mobile devices.

:::grid
- **Mobile Responsive**
  Touch-optimized interface that adapts seamlessly to smartphones and tablets with gesture support and mobile-specific
  layouts.
- **Accessibility Features**
  Screen reader compatibility, high contrast modes, and semantic HTML for inclusive access.
:::
