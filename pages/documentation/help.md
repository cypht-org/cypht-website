        <div class="doc-subsection-header">
            <a href="#common_issues">Common Issues and Solutions</a>
        </div>

        <div class="accordion issue-accordion" id="issuesAccordion">
            <div class="accordion-item">
                <h2 class="accordion-header">
                    <button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#issue1">
                        <i class="bi bi-exclamation-triangle me-2"></i> Login Problems
                    </button>
                </h2>
                <div id="issue1" class="accordion-collapse collapse" data-bs-parent="#issuesAccordion">
                    <div class="accordion-body">
                        <p><strong>Symptoms:</strong> Can't log in or login page doesn't load</p>
                        <p><strong>Solutions:</strong></p>
                        <ul>
                            <li>Check session configuration in PHP</li>
                            <li>Verify database connection</li>
                            <li>Ensure proper file permissions</li>
                            <li>Clear browser cookies and cache</li>
                        </ul>
                    </div>
                </div>
            </div>

            <div class="accordion-item">
                <h2 class="accordion-header">
                    <button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#issue2">
                        <i class="bi bi-envelope me-2"></i> Email Connection Issues
                    </button>
                </h2>
                <div id="issue2" class="accordion-collapse collapse" data-bs-parent="#issuesAccordion">
                    <div class="accordion-body">
                        <p><strong>Symptoms:</strong> Can't connect to email servers</p>
                        <p><strong>Solutions:</strong></p>
                        <ul>
                            <li>Verify IMAP/SMTP settings</li>
                            <li>Check firewall and port access</li>
                            <li>Test with external email client</li>
                            <li>Enable debug mode for detailed logs</li>
                        </ul>
                    </div>
                </div>
            </div>

            <div class="accordion-item">
                <h2 class="accordion-header">
                    <button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#issue3">
                        <i class="bi bi-speedometer2 me-2"></i> Performance Issues
                    </button>
                </h2>
                <div id="issue3" class="accordion-collapse collapse" data-bs-parent="#issuesAccordion">
                    <div class="accordion-body">
                        <p><strong>Symptoms:</strong> Slow loading or poor performance</p>
                        <p><strong>Solutions:</strong></p>
                        <ul>
                            <li>Optimize database queries</li>
                            <li>Enable PHP OPcache</li>
                            <li>Configure proper caching</li>
                            <li>Check server resources</li>
                        </ul>
                    </div>
                </div>
            </div>
        </div>

        </div>
        <span class="doc-section-text">
            If you can't find a solution, report your issue to get help from the community.

        <div class="doc-subsection-header">
            <a href="#before_reporting">Before Reporting</a>
        </div>
        <p>Help us help you by providing complete information:</p>

        <div class="feature-card">
            <h6><i class="bi bi-clipboard-check"></i> Issue Report Checklist</h6>
            <ul>
                <li>✅ Search existing issues first</li>
                <li>✅ Provide Cypht version</li>
                <li>✅ Include PHP version and server info</li>
                <li>✅ Describe steps to reproduce</li>
                <li>✅ Include error messages and logs</li>
                <li>✅ Mention recent changes</li>
            </ul>
        </div>
