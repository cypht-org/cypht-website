## Powerful Email Composition {#overview}

Cypht provides a flexible and powerful email composition experience with support for multiple formats, rich editing
options, and seamless integration with your configured accounts.

:::grid
- **Versatile Composing**
  Create messages in plain text, HTML, or Markdown with advanced formatting options
:::

## Multiple Format Support {#format_options}

Choose the format that best suits your communication needs, from simple plain text to rich HTML or structured
Markdown.

### Plain Text {#plain_text}

:::grid
- **Simple & Universal**
  Plain text emails are lightweight, load quickly, and are compatible with all email clients and devices.
- **Secure & Reliable**
  Plain text eliminates security risks associated with HTML and ensures your message is displayed consistently
  everywhere.
:::

### HTML Format {#html_format}

:::grid
- **Rich Formatting**
  Create visually appealing emails with formatting, colors, links, and embedded content using the built-in HTML
  editor.
- **Professional Appearance**
  Perfect for business communications, newsletters, and messages that require visual presentation.
:::

### Markdown Format {#markdown_format}

:::grid
- **Markdown Support**
  Compose messages in Markdown for structured content that's easy to write and read. Markdown formatted messages are
  automatically converted to HTML before being sent, combining the simplicity of Markdown with the display
  capabilities of HTML.
:::

:::grid
- **Developer Friendly**
  Perfect for technical documentation, code snippets, and structured communication.
- **Structured Content**
  Use headers, lists, links, and code blocks to create well-organized messages.
:::

## Editor Features {#editor_features}

Advanced editing capabilities that make composing emails efficient and enjoyable.

:::grid
- **Rich Text Editor**
  Built-in WYSIWYG editor for HTML messages with formatting tools, font styles, and text alignment options.
- **Markdown Editor**
  Modern JavaScript Markdown editor with live preview and advanced editing features.
- **Attachments**
  Easily attach files to your emails with drag-and-drop support and file size indicators.
- **Image Embedding**
  Embed images directly in your HTML emails for rich visual content.
:::

## Account Integration {#account_integration}

Seamlessly compose and send emails using any of your configured accounts with intelligent account management.

### Profile Management {#profile_management}

:::grid
- **Flexible Profiles**
  Combine IMAP accounts with SMTP accounts and setup signatures and reply-to details for each profile.
- **Quick Account Switching**
  Switch between sending accounts on the fly without losing your composed message.
:::

### Signatures & Identity {#signatures}

:::grid
- **Custom Signatures**
  Create and manage multiple signatures for different accounts and purposes.
- **Reply-To Configuration**
  Set custom reply-to addresses for each profile to manage responses effectively.
:::

## Advanced Features {#advanced_features}

Powerful features that enhance your email composition workflow and productivity.

:::grid
- **Smart Reply**
  Intelligent reply functionality that automatically quotes original messages and manages reply headers.
- **Forward Management**
  Easily forward messages with proper formatting and attachment handling.
- **Contact Integration**
  Auto-complete addresses from your contact book and recently used addresses.
- **Draft Management**
  Automatically save drafts and recover them if your browser closes unexpectedly.
- **Scheduled Sending**
  Schedule emails to be sent at specific times for optimal delivery.
- **Delivery Receipts**
  Get confirmation when your emails are delivered to the recipient's inbox.
:::

## Security & Privacy {#security_privacy}

Built-in security features to protect your communications and maintain your privacy.

:::grid
- **Content Filtering**
  HTML content is filtered through HTMLPurifier to remove potentially malicious code while preserving valid
  formatting.
- **Secure Transmission**
  Supports TLS/STARTTLS for SMTP connections to ensure your emails are transmitted securely.
:::

## Productivity Features {#productivity}

Tools and shortcuts that make email composition faster and more efficient.

:::grid-sm
- **Keyboard Shortcuts**
  Quick keyboard shortcuts for common actions like sending, saving drafts, and formatting.
- **Templates**
  Create and use email templates for frequently sent messages.
- **Spell Check**
  Built-in spell checking to ensure professional communication.
:::
