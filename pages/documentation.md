      <div id="what-is-cypht" class="doc-section active">
        <h2>What is Cypht?</h2>
        <p>Cypht is a lightweight, modular webmail client that unifies multiple email accounts into one simple, secure interface. Whether you use Gmail, Outlook, or IMAP, Cypht helps you manage all your inboxes from one place.</p>
      </div>

      <div id="key-features" class="doc-section">
        <h2>Key Features</h2>
        <ul>
          <li>Unified inbox for multiple accounts</li>
          <li>Powerful search and filtering system</li>
          <li>Integrated contact and calendar management</li>
          <li>Open-source and privacy-focused</li>
          <li>Modular architecture for easy customization</li>
        </ul>
      </div>

      <div id="requirements" class="doc-section">
        <h2>System Requirements</h2>
        <p>Before installation, make sure your environment meets the following requirements:</p>
        <ul>
          <li>PHP 7.4+ or 8.x</li>
          <li>Web server (Apache, Nginx, etc.)</li>
          <li>MySQL / SQLite database</li>
          <li>Modern browser (Chrome, Firefox, Safari, Edge)</li>
        </ul>
      </div>

      <div id="versions" class="doc-section">

        <h2>Installation & Setup</h2>
        <p>Follow these steps to install Cypht on your local environment or production server.</p>
        <pre><code># Clone repository git clone https://github.com/jasonmunro/cypht.git
        cd cypht
        # Install dependencies
        composer install
        npm install
            </code></pre>
